# 🌿 PlantPulse — AI-Powered Plant Disease Monitoring

> **Detect. Understand. Monitor.**

PlantPulse is an AI-assisted image classification system designed to analyze plant leaf images and identify visible disease conditions.

Instead of stopping at disease classification, PlantPulse focuses on **explainability and disease progression monitoring** — helping users understand *why* a condition was predicted and how the plant's visible symptoms change across repeated scans.

---

## 🎯 Problem Statement

### IC-06 — Plant Disease Image Classifier

Develop an image classification system that classifies plant leaf images according to visible disease categories.

The system analyzes:

* 🍃 Leaf color
* 🔬 Texture patterns
* 📐 Shape characteristics
* 🩹 Visible lesion characteristics

The classifier is designed for agricultural image-based health monitoring.

---

```text
Health Timeline
    ↓
Early Warning
```

### Core Innovation

**Don't just detect the disease. Understand its progression.**

PlantPulse focuses on two key ideas:

### 1. Explainable Prediction

The system highlights visible characteristics that contribute to the predicted condition, such as:

* Lesion patterns
* Discoloration
* Texture variation
* Shape anomalies

### 2. Disease Progression Monitoring

Instead of analyzing every image independently, PlantPulse can compare repeated scans over time.

Example:

```text
Sep 18 → Low
Sep 21 → Moderate
Sep 24 → High
```

This creates a simple **Plant Health Timeline** and can indicate a worsening trend.

## 🧠 AI Pipeline

The planned classification pipeline is:

```text
Input Leaf Image
       ↓
Image Preprocessing
       ↓
Feature Extraction
       ↓
Image Classification Model
       ↓
Disease Prediction
       ↓
Confidence + Severity
       ↓
Visual Explanation
```

Possible model approaches include CNN-based image classification and transfer learning.

The final model architecture will depend on dataset availability, training time, and hackathon constraints.
